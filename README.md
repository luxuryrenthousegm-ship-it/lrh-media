## REGLAS FIJAS DE CONTENIDO (Gregory, 15 nov 2026) — leer antes de crear cualquier pieza
- PROHIBIDO etiquetar una publicación, historia o anuncio con la audiencia: nunca "para propietarios", "para clientes", "para inquilinos", "tip para inquilinos", "for owners", "for tenants" ni nada parecido (ni en pastillas, títulos o textos). El mensaje le habla a quien corresponde sin decirlo. Pensar siempre como un ejecutivo senior de marketing. Revisar cada imagen antes de programarla y rehacer cualquiera que tenga una etiqueta así.
- Tipografía de tendencia aprobada para piezas elegantes: Instrument Serif (títulos) + Manrope en mayúsculas espaciadas (ver tools/story_doral1051.py).

- PROHIBIDO usar la palabra "barata" / "barato" (ni "cheap") en cualquier publicación, historia o anuncio.
